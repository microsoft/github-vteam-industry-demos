# Industries

Industry-specific demos are organized under the following directories:

- Professional Services
- Financial Services
- Retail & Consumer Goods
- High Tech / Software / ISV
- Manufacturing
- Transport & Logistics
- Real Estate & Construction
- Healthcare & Life Sciences
- Public Sector & Education
- Utilities / Infrastructure

Each demo should have its own folder containing:
- README.md
- Architecture diagrams
- Source code
- Deployment instructions
- Demo walkthrough
