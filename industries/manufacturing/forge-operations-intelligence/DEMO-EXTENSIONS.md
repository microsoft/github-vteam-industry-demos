# Six optional future Copilot demonstrations

**Ideas only: not implemented or authorized in Phase 3.** Each is a small,
separately approved demonstration using the existing synthetic app—not a new
platform, Azure resource or policy workaround.

1. **Quick incident filters:** add a compact “high severity + unresolved” preset
   using existing client-side incident data.
2. **Markdown plan export:** download the current human-edited plan with response
   attribution, review status and the synthetic-only disclaimer; no PDF service.
3. **KPI explanation tooltips:** explain weighted OEE inputs and why overlapping
   incident durations do not sum to line downtime.
4. **Two-line comparison:** compare existing output, target, downtime and OEE
   side by side without extra telemetry or AI calls.
5. **Activity filters:** narrow the existing history by incident or event kind
   while preserving timestamp order and real response attribution.
6. **Readable edit comparison:** show a small before/after summary of the current
   plan draft, emphasizing that saving edits invalidates approval.

None introduces autonomous equipment control, real customer data, automatic AI
retries, extra model capacity, persistent-storage claims or public-policy bypasses.
