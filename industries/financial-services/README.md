- **[Open the live application](https://ca-kyc-fs01.salmonpebble-2b6fa79e.norwayeast.azurecontainerapps.io/)**

- **[GitHub Copilot CLI + Squad live demo changes](./kyc-case-investigation-cockpit/LIVE-DEMO-QUICK-CHANGES.md)**

> The demo uses synthetic KYC/customer data. AI recommendations are advisory and the final action remains human-controlled.

This folder contains industry-specific solution plays, demos, architecture patterns, and reusable assets for Financial Services customers.
