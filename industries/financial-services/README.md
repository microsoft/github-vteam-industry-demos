# Financial Services

This folder contains industry-specific solution plays, demos, architecture patterns, and reusable assets for Financial Services customers.

## Suggested Scenarios

- Banking Assistant
- Fraud Detection Agent
- Mortgage Advisor
- Customer Onboarding Copilot
- Regulatory Compliance Assistant
- Risk Assessment Solution

## Folder Structure

Each demo should have its own folder:

financial-services/
└── demo-name/
    ├── README.md
    ├── architecture/
    ├── source/
    ├── deployment/
    └── assets/

## Contributing

Place new Financial Services solutions in a dedicated folder and include:
- Business challenge
- Architecture diagram
- Deployment instructions
- Demo walkthrough
- Customer value
